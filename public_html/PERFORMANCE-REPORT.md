# Проверка производительности — 17 сентября 2026

Изменения выполнены локально, без публикации и деплоя. Тексты и компоновка сохранены; Vimeo заменён постером с кнопкой, для ошибок карты добавлено сообщение. Fallback заголовка используется в metadata и breadcrumbs, но не добавляет второй H1 в текст статьи.

## Что исправлено

- Удалена транзакция на весь запрос `/admin`. Чтение JSON использует атомарно заменяемый файл без writer lock. Формы, аутентификация и загрузки выполняются без общей блокировки.
- `save_json` атомарно проверяет revision и записывает JSON под короткой межпроцессной транзакцией. Конкурирующее изменение получает 409. Revision формы фиксируется до чтения данных админки, чтобы устаревшая форма не получила новую revision в конце рендера. Rate limit входа и счётчик скачиваний сохраняют атомарные read-modify-write транзакции.
- Inter 4.1 размещён локально, четыре используемых normal-начертания 400/500/600/700, `font-display: swap`; Google Fonts `@import` удалён. Лицензия включена.
- Метрика, Webvisor и clickmap отсутствуют в development и `/admin`; в production инициализация выполняется после load через idle callback (или таймер).
- `version-check.js` больше не подключается и не перезагружает страницу, не удаляет Cache Storage. CSS/JS получают `?v=1.1.4`.
- Публичные GET не декодируют и не создают изображения. Список городов выбирает одну обложку, считает имена остальных фотографий без построения галереи. Подготовка — `scripts/prepare_images.py`; загрузки коллекций создают миниатюры сразу вне транзакции. Оригиналы остаются в просмотрщике.
- Подготовлены 22 WebP: три обложки постов, три обложки городов и 16 изображений книг/коллекций. Посты используют отдельный `card_image`, вписанный в 960×480 без обрезки. JPG и полноразмерные пути сохранены.
- Mapbox JS/CSS загружаются через IntersectionObserver при видимости карты; для браузера без него есть кнопка. Обработаны отсутствие токена, ошибка загрузки скрипта, ошибка карты и таймаут 20 секунд.
- Vimeo iframe создаётся только по клику. Постер исключён из набора изображений галереи, чтобы клик не открывал одновременно просмотрщик.
- Поиск использует один Promise на загрузку индекса, проверяет HTTP-ответ, показывает ошибку и допускает повторную попытку; устаревшие результаты игнорируются после нового ввода, очистки или закрытия.
- Flask и production `.htaccess` задают годовой Cache-Control только статике с непустым `v`; без версии и в локальном Flask используется `no-cache`. В Apache разрешён каталог fonts.

## Ограничения и Mapbox

Существовавший публичный токен проверен через Mapbox Styles API: **401 `Not Authorized - Invalid Token`** для Referer `http://localhost:5044/`, `http://127.0.0.1:5044/`, `https://ruslanfatikhov.ru/`, `https://www.ruslanfatikhov.ru/`. Последний домен взят из контактного адреса проекта, фактический production-домен требует подтверждения. Недействительный токен удалён из кода; используется `MAPBOX_ACCESS_TOKEN` из окружения/.env. Новый токен не предоставлен, поэтому успешную загрузку карты и настройки allowed URLs в аккаунте подтвердить нельзя. Приложение теперь показывает сообщение вместо пустого фона.

По [официальной документации Mapbox](https://docs.mapbox.com/accounts/guides/tokens/) localhost нужно явно разрешать при использовании URL restrictions. Ошибка недействительного токена не позволяет заключить, что доменные ограничения настроены правильно. Настройки аккаунта не менялись.

Интерактивная проверка страниц и браузерные FCP/LCP не выполнены: инструмент не нашёл подключённого браузера; попытка открыть Safari завершилась `native pipe closed before response`. Визуальная проверка выше относится к растровому сравнению обложек, а не к полному browser screenshot. Проверки JavaScript выполнялись в Node с моделью DOM. `.htaccess` не запускался под production Apache; заголовки проверены тестами Flask.
